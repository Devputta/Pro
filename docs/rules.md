# Engineering Rules & Guidelines

## 1. Code Style & Standards
- Write clean, semantic HTML5 structure.
- Utilize utility-first CSS classes (Tailwind CSS) for rapid, consistent styling.
- Keep JavaScript modular, event-driven, and free of unnecessary global variables.

## 2. Commit Message Convention (Conventional Commits)
- `feat:` New feature or capability
- `fix:` Bug fix or patch
- `docs:` Documentation updates
- `refactor:` Code restructuring without functional changes
- `style:` Formatting, missing semicolons, etc.
