# Deployment Guide

## Deploying to GitHub Pages
1. Push your code to your GitHub repository (`Devputta/vibe-portfolio`).
2. Navigate to your repository **Settings** > **Pages**.
3. Under **Build and deployment**, select **Source** as `Deploy from a branch`.
4. Choose `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio will be live at `https://devputta.github.io/<repo-name>/`.

## Deploying to Vercel (Alternative)
1. Import your GitHub repository into Vercel.
2. Leave build settings as default (static site).
3. Click **Deploy** for instant global edge distribution.
