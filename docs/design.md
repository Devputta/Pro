# Design Guidelines

## 1. Color Palette
- **Background (Dark):** `#090a0f`
- **Card Background:** `#12141c`
- **Primary Accent (Neon Purple):** `#8b5cf6`
- **Secondary Accent (Cyan):** `#06b6d4`
- **Text Primary:** `#f8fafc` (Slate 50)
- **Text Secondary:** `#94a3b8` (Slate 400)

## 2. Typography
- **Primary Font:** 'Plus Jakarta Sans', sans-serif
- **Monospace Font:** 'JetBrains Mono', monospace

## 3. Visual Effects
- **Glow Effects:** Soft box-shadows using purple and cyan opacities (`box-shadow: 0 0 40px -10px rgba(139, 92, 246, 0.3);`).
- **Glassmorphism:** Backdrop blur filters (`backdrop-blur-md bg-darkBg/80`).
