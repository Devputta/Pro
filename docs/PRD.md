# Project Requirements Document (PRD)

## 1. Executive Summary
This document outlines the core specifications, user flows, and success metrics for the vibe-coding portfolio ecosystem.

## 2. Problem Statement
Developers often struggle to present creative, non-traditional ("vibe") projects in a way that appeals to formal corporate recruiters while maintaining their unique engineering identity.

## 3. Target Audience
- Software Engineering Recruiters & Hiring Managers
- Open-Source Collaborators
- Fellow Engineers

## 4. Functional Requirements
- **Interactive Portfolio Web App:** Single-page design with dark/neon aesthetics and responsive card layouts.
- **Mobile Viewer Simulator:** Built-in device viewport to preview mobile-first application states.
- **GitHub Integration:** Direct linking and stats display for public repositories (`Devputta`).

## 5. Non-Functional Requirements
- **Performance:** Optimized asset loading with zero external bloat besides Tailwind and Lucide icons.
- **Accessibility:** High-contrast color palette compliant with dark mode standards.
