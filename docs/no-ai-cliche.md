# Anti-AI Slop & Editorial Rules

1. **Zero Conversational Filler:** Never start documentation with robotic intros like *"Sure, here is your document..."* or end with *"I hope this helps!"*
2. **Pragmatic Naming:** Avoid generic placeholder names like `foo`, `bar`, or overly dramatic buzzwords. Use concrete engineering terminology.
3. **Intentional Formatting:** Use clean markdown tables, precise code blocks, and varied sentence lengths to maintain an authentic human author voice.
4. **Code Comments:** Write comments explaining complex architectural trade-offs or quirks, never narrating obvious syntax.
