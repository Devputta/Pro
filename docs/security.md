# Security Policy

## 1. Reporting a Vulnerability
If you discover any security issues or vulnerabilities within this repository, please reach out directly via GitHub or open a private advisory.

## 2. Environment Variables & Secrets
- Never commit API keys, personal access tokens, or database credentials into public repositories.
- Utilize `.env.example` templates for configuration placeholders.

## 3. Dependency Management
- Regularly review external scripts and CDN dependencies for integrity and security updates.
